# Исходные данные

Сюда кладутся исходные документы вашей темы — PDF, TXT, MD. Собираются дома
после практики 1, используются начиная с практики 2.

Каталог намеренно пуст: сами документы в репозиторий не попадают, их исключает
`.gitignore`. Этот файл нужен, чтобы каталог существовал после клонирования
и после распаковки архива.

Собранные документы не удаляйте даже при сужении объёма на практике 5: лишние
источники просто перестают индексироваться, но остаются на диске.
